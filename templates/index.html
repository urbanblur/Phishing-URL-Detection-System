How It Works

01

URL Input

The user enters a URL into the detection system.

02

Feature Extraction

The URL is converted into character-level TF-IDF features.

03

ML Analysis

A Logistic Regression model analyzes the extracted URL representation.

04

Prediction

The system classifies the URL as phishing or legitimate.

Project Information

Project: Phishing and Malicious URL Detection System

Approach: Machine Learning based URL classification

Feature Representation: Character-level TF-IDF

Classifier: Logistic Regression

Evaluation: Domain-disjoint train/test evaluation

Dataset: PhiUSIIL Phishing URL Dataset

⚠️ This system is designed for phishing URL detection. A legitimate prediction does not guarantee that a website is completely safe.
